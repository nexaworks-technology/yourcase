## Changelog

All notable changes to the YourCase web client (frontend) will be documented here.

### 2026-01-05
- Navbar → “Recent toasts” quick view: export/import actions (JSON/CSV/ZIP), filter, pinned controls, keyboard shortcuts, quick stats pill, defaults badges, export chip with deep‑link, reduced‑motion skeletons, and transient “Copied” badges.
- Settings → Recent toasts: CSV Mapping Modal (date formats, persisted mapping + toggles), Import Preview summary, Export preview modal (JSON/CSV/ZIP), Clear/Restore badge, Reset dismissal, accessibility improvements (aria‑busy skeletons, keyboard hints).
- Diagnostics: route retry telemetry (session logging), preview/copy/download/clear, and expanded RouteChunkBoundary with retry backoff, offline banner, copy/report, reduced‑motion countdown.
- Build & performance: manual chunking for large deps and pages; clean production build.
- Docs: updated root and frontend READMEs; added docs/ with feature guides.
