How to run (frontend)

cd ../frontend
npm install
npm run dev   # http://localhost:5173
npm run build # outputs to dist/

Notes

  • Reduced‑motion is respected across new animations and skeletons.
  • Session/Local storage keys are listed in the READMEs and feature guides.
